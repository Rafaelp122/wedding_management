# How-To: Executando Testes E2E com Playwright

> **Objetivo:** Executar e depurar os testes ponta a ponta da interface.

---

## Executando Suíte E2E

```bash
cd frontend
# Executar todos os testes E2E em headless mode
npx playwright test

# Executar com interface gráfica para depuração
npx playwright test --ui
```
